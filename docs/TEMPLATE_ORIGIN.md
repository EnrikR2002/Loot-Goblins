# SYFER Factory origin

Loot Goblins was **adopted** into SYFER Roblox Factory version `0.1.0` on 2026-10-30, at Factory commit `853c1a6ad01a0c75053b0826e0c05e526eb11eb3`. It was **not** generated by the Factory: the game was built from October 3, 2026 onward with an earlier version of the same workflow, and the Factory starter was later extracted from it.

The adoption brought the shared infrastructure that was an older copy of the Factory's (memory tooling, build/play/dev/check scripts, CI tool cache, onboarding docs, the `assets/` Library root) up to the 0.1.0 starter, and kept every Loot Goblins customization. `.syfer/factory.json` records the baseline and an informational list of those customizations; `docs/reports/2026-10-30-factory-adoption.md` has the details.

Reusable infrastructure/assets/components belong to `EnrikR2002/SYFER-Roblox-Factory`. Reusable cross-game lessons/quality knowledge belong to the Factory Knowledge subsystem at `EnrikR2002/SYFER-Roblox-Knowledge`. Later shared changes arrive through versioned Factory migrations; never copy a newer starter over this game.
