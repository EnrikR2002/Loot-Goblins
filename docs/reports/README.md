# Reports

One file per task, named YYYY-MM-DD-<topic>.md: what changed and why, evidence, tests and their limitations, and the human playtest checklist. Screenshots go next to the report.

Reports are history. Current game facts belong in [../GAME_DESIGN.md](../GAME_DESIGN.md). Do not rewrite old results as present evidence. Historical file paths and branch names can refer to earlier files that have since been consolidated. Generated GAME_GUIDE.md embeds dated reports in full.
